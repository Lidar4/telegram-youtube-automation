# Nibhir Messenger roadmap

## Phase 1 — UI foundation
- Messenger-style responsive layout
- Dark/light theme
- Chat list and search
- Modern message bubbles
- Room creation/join flow
- Message copy/edit/delete/reply actions
- Mobile sidebar and composer polish

## Phase 2 — Realtime backend
- Supabase project configuration
- Profiles, rooms, members and messages tables
- Row Level Security policies
- Supabase Realtime subscriptions
- Cross-device room messaging

## Phase 3 — Messaging UX
- Typing indicators
- Sent/delivered/read states
- Unread counts
- Reactions
- Pin/forward
- Message search

## Phase 4 — Media
- Image/file upload
- Supabase Storage
- Image preview
- Voice messages
- Media gallery

## Phase 5 — Privacy and safety
- Room/member permissions
- Invite links
- Block/report
- Rate limiting and abuse controls
- Secure attachment access
- Optional end-to-end encryption design

## Phase 6 — Production
- Error/loading states
- Accessibility pass
- Performance optimization
- PWA/install experience
- Deployment and monitoring
